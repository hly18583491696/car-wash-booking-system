  - `SELECT id, name FROM services WHERE name REGEXP '[ÃÂ]';`
  - `SELECT id, description FROM services WHERE description REGEXP '[ÃÂ]';`

## 统一字符集到 utf8mb4（不改变文本内容）
- 库：`ALTER DATABASE carwash_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`
- 表（逐表）：
  - `ALTER TABLE users CONVERT TO CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`
  - `ALTER TABLE services CONVERT TO CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`
  - `ALTER TABLE bookings CONVERT TO CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`
  - `ALTER TABLE system_config CONVERT TO CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`
  - `ALTER TABLE feedback CONVERT TO CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`
  - `ALTER TABLE time_slots CONVERT TO CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`

## 修复已存在乱码（两种场景）
- 场景A：列类型为 `latin1`，数据实为 UTF-8 字节（推荐二段式修复）
  1) 暂改为二进制以保留原始字节：
    - `ALTER TABLE services MODIFY name VARBINARY(100);`
    - `ALTER TABLE services MODIFY description VARBINARY(1024);`
  2) 改回 UTF-8 文本类型：
    - `ALTER TABLE services MODIFY name VARCHAR(100) CHARACTER SET utf8mb4;`
    - `ALTER TABLE services MODIFY description TEXT CHARACTER SET utf8mb4;`
  3) 对其他表中文列同样处理（`users.real_name`、`bookings.notes`、`system_config.config_value`、`feedback.content/reply`）。
- 场景B：列为 `latin1`，数据确以 `latin1` 存储，希望转为 UTF-8（样本验证后批量）：
  - `UPDATE services SET name = CONVERT(CAST(CONVERT(name USING latin1) AS BINARY) USING utf8mb4) WHERE name REGEXP '[ÃÂ]';`
  - `UPDATE services SET description = CONVERT(CAST(CONVERT(description USING latin1) AS BINARY) USING utf8mb4) WHERE description REGEXP '[ÃÂ]';`
