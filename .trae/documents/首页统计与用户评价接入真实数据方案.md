## 目标
- 将首页“统计数据（stats-section）”与“用户评价（testimonials-section）”由静态文案替换为真实数据库数据
- 完善评价功能：支持从后端拉取最新评价并展示评分、内容与时间

## 后端接口
- 新增公共统计接口：`GET /api/public/stats/summary`
  - 字段：
    - `usersCount`：`users` 表有效用户数（`deleted=0 && status=1`）
    - `completedBookings`：`bookings` 表 `status='completed'` 计数
    - `satisfactionPercent`：`feedback` 表评分均值/5×100（`rating IS NOT NULL && deleted=0`）
    - `avgPaymentResponseMinutes`：`payments` 表近N条（如200）已支付订单的支出完成耗时（`TIMESTAMPDIFF(MINUTE, created_at, paid_at)` 的均值）
- 新增公共评价接口：`GET /api/public/feedback/latest?limit=6`
  - 字段：`id, rating, content, createdAt, userMaskedName, orderNo(optional)`
  - 数据来源：`feedback` 表（`deleted=0`，`rating IS NOT NULL`，`content IS NOT NULL`，按 `created_at DESC`），`userMaskedName` 采用用户名脱敏（如 `u***r`）
- 说明：以上均为公共只读接口，不需要管理员权限；确保不泄露敏感信息

## 前端接入
- 统计数据：
  - 在 `frontend/src/views/Home.vue` 与 `EnhancedHome.vue` 的 `stats-section` 中，加载时调用 `/api/public/stats/summary`，把四个指标分别填入：
    - 服务用户 → `usersCount`
    - 完成订单 → `completedBookings`
    - 满意度 → `satisfactionPercent`（格式化为`98%`样式）
    - 响应时间 → `avgPaymentResponseMinutes`（格式化为`24h`或`XhYm`）
  - 动画数字：复用 `components/AnimatedCounter.vue`（`displayValue` 绑定接口返回值）
- 用户评价：
  - 在 `Home.vue` 与 `EnhancedHome.vue` 的 `testimonials-section`，将 `testimonials` 静态数组替换为 API 拉取的列表
  - 展示：评分星级（1–5）、内容、用户脱敏名、创建时间（`yyyy-MM-dd HH:mm`），保留原有网格与样式
  - 空态：当列表为空显示“暂无评价”，与现有空态样式一致
- API 封装：在 `frontend/src/api` 新增 `public.js` 或扩展 `realApi`，添加 `getStatsSummary()`、`getLatestFeedback(limit)` 方法
