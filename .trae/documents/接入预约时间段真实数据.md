## 目标
- 让预约页面时间段 `div` 从 MySQL 真实数据渲染，并保持现有 UI 与交互（禁用、已满、高亮）。

## 后端接口
- 新增控制器 `com.carwash.controller.TimeSlotController`，基础路径 `'/api/time-slots'`。
- 提供端点：
  - `GET /available?date=YYYY-MM-DD`：返回指定日期可用时间段列表（来源 `TimeSlotServiceImpl.getAvailableTimeSlots` backend/src/main/java/com/carwash/service/impl/TimeSlotServiceImpl.java:61-68）。
  - `GET /find?date&timeRange`：按日期+时间范围返回对应时间段ID（基于 `TimeSlotMapper.selectAvailableByDate` backend/src/main/java/com/carwash/mapper/TimeSlotMapper.java:25-26` 的匹配）。
  - `GET /{id}`：返回时间段详情。
- 响应结构建议：`{ id, date, start_time, end_time, max_bookings, current_bookings, status }`，与实体一致（backend/src/main/java/com/carwash/entity/TimeSlot.java:31-81）。
- 安全配置：`/api/time-slots/available` 已白名单（backend/src/main/java/com/carwash/config/SecurityConfig.java:81），其余接口默认认证或按需开放。

## 数据库
- 使用 MySQL 中 `time_slots` 表（sql/init.sql:62-77）。初始化数据已包含未来时间段（sql/init.sql:202-320）。
- 真实可用性以 `current_bookings < max_bookings` 与 `status=1` 判定（服务层实现）。

## 前端改造
- 页面位置：`frontend/src/views/Appointment.vue`。
- 替换静态时间段：
  - 现有静态数组在 `frontend/src/views/Appointment.vue:385-415`。
  - 改为使用 `timeSlotsApi.getAvailableTimeSlots(date)`（frontend/src/api/timeSlots.js:11-15），在 `selectedDate` 变化或 `onMounted` 拉取。
- 数据映射：
  - `time = HH:mm-HH:mm`，由 `start_time`/`end_time` 组装。
  - `available = max_bookings - current_bookings`，`busy = available === 0`。
  - `disabled`：若为当天且该时间段已过去则禁用（保留现有逻辑）。
- 交互保持：
  - 选择槽位 `selectTimeSlot(slot)`（frontend/src/views/Appointment.vue:438-441）维持原判定。
  - UI 类名与结构不变（frontend/src/views/Appointment.vue:77-99）。
