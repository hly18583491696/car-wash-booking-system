## 后端重启

* 停止当前后端进程：关闭正在运行的 `mvn spring-boot:run` 终端进程。

* 重新启动：在 `backend/` 目录运行 `mvn spring-boot:run`，观察控制台日志出现“汽车洗车服务预约系统启动成功”。

* 启动验证：

  * 访问公开接口 `http://localhost:8080/api/debug/health`（`/api/debug/**` 允许匿名），确认返回 `code=200`。

  * 可选：登录后再访问受保护接口（如支付相关）确认鉴权正常。

## 前端重启

* 停止当前前端进程：关闭正在运行的 `npm run dev` 终端进程。

* 重新启动：在 `frontend/` 目录运行 `npm run dev`。

* 启动验证：打开 `http://localhost:3003/`，确认首页可访问；确保路由与静态资源正常。
