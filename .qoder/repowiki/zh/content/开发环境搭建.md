## 项目简介

汽车洗车服务预约系统是一个现代化的汽车洗车服务预约管理系统，采用前后端分离架构，包含完整的用户注册登录、服务预约管理、数据统计仪表板和管理员后台系统等功能。

### 技术栈

**后端技术栈：**
- Spring Boot 3.x
- MyBatis Plus
- JWT 认证
- Redis 缓存
- MySQL 数据库

**前端技术栈：**
- Vue.js 3.x
- Element Plus UI
- Vite 构建工具
- ECharts 数据可视化

## 软件安装

### Java JDK 安装

#### Windows 环境

1. **下载 JDK**
   - 访问 [Oracle JDK](https://www.oracle.com/java/technologies/javase-jdk17-downloads.html) 或 [OpenJDK](https://openjdk.org/projects/jdk/17/)
   - 下载对应 Windows 平台的 JDK 17 安装包

2. **安装 JDK**
   ```cmd
   # 运行下载的安装包
   # 默认安装路径：C:\Program Files\Java\jdk-17
   ```

3. **配置环境变量**
   ```cmd
   # 设置 JAVA_HOME 环境变量
   setx JAVA_HOME "C:\Program Files\Java\jdk-17"
   
   # 添加到 PATH
   setx PATH "%JAVA_HOME%\bin;%PATH%"
   ```

4. **验证安装**
   ```cmd
   java -version
   # 应显示：java version "17.x.x"
   ```

### Node.js 安装

#### Windows 环境

1. **下载 Node.js**
   - 访问 [Node.js 官网](https://nodejs.org/)
   - 下载 LTS 版本（推荐）

2. **安装 Node.js**
   ```cmd
   # 运行下载的安装包
   # 默认安装路径：C:\Program Files\nodejs\
   ```

3. **验证安装**
   ```cmd
   node -v
   npm -v
   # 应显示版本号，如 v18.x.x
   ```

### MySQL 安装

#### Windows 环境

1. **下载 MySQL**
   - 访问 [MySQL 官网](https://dev.mysql.com/downloads/mysql/)
   - 下载 MySQL Community Server

2. **安装 MySQL**
   ```cmd
   # 运行下载的安装包
   # 设置 root 用户密码（建议设置为：123456）
   # 配置 MySQL 服务
   ```

3. **验证安装**
   ```cmd
   mysql -u root -p
   # 输入密码：123456
   # 如果进入 MySQL 命令行，则安装成功
   ```

### Redis 安装

#### Windows 环境

参考 [Redis安装和配置指南.md](file://Redis安装和配置指南.md) 中的详细说明，推荐使用以下方法之一：

1. **使用 Chocolatey 安装**
   ```cmd
   choco install redis
   ```

2. **手动安装**
   ```cmd
   # 下载 Redis Windows 版本
   # 解压到 C:\redis
   # 将 C:\redis 添加到系统 PATH
   ```

3. **启动 Redis 服务**
   ```cmd
   # 临时启动
   redis-server
   
   # 或作为 Windows 服务启动
   redis-server --service-install redis.windows.conf --loglevel verbose
   redis-server --service-start
   ```

## 数据库配置

### 创建数据库

1. **登录 MySQL**
   ```cmd
   mysql -u root -p
   ```

2. **创建数据库**
   ```sql
   CREATE DATABASE carwash_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

3. **退出 MySQL**
   ```sql
   EXIT;
   ```

### 初始化数据库

1. **执行初始化脚本**
   ```cmd
   # 方法一：使用 MySQL 命令行
   mysql -u root -p carwash_db < sql/init.sql
   
   # 方法二：使用 MySQL Workbench
   # 打开 init.sql 文件并执行
   ```

2. **验证初始化结果**
   ```sql
   USE carwash_db;
   SHOW TABLES;
   SELECT COUNT(*) FROM users;
   SELECT COUNT(*) FROM services;
   ```

## 常见问题排查

### 端口冲突

1. **检查端口占用**
   ```cmd
   # 检查 8080 端口
   netstat -ano | findstr :8080
   
   # 检查 3000 端口
   netstat -ano | findstr :3000
   
   # 检查 6379 端口
   netstat -ano | findstr :6379
   ```

2. **解决方案**
   - 修改 `application.yml` 中的端口配置
   - 停止占用端口的进程
   - 使用不同的端口号

### 依赖下载失败

1. **检查网络连接**
   - 确保网络稳定
   - 配置 Maven 镜像源

2. **Maven 配置**
   ```xml
   <!-- 在 ~/.m2/settings.xml 中添加 -->
   <mirrors>
     <mirror>
       <id>aliyun</id>
       <name>Aliyun Maven</name>
       <url>https://maven.aliyun.com/repository/public</url>
       <mirrorOf>central</mirrorOf>
     </mirror>
   </mirrors>
   ```

3. **重新下载依赖**
   ```cmd
   mvn clean install -U
   ```

### 数据库连接失败

1. **检查 MySQL 服务**
   ```cmd
   net start mysql
   ```

2. **验证数据库连接**
   ```cmd
   mysql -u root -p carwash_db
   ```

3. **检查连接配置**
   - 确认数据库名称正确
   - 确认用户名密码正确
   - 确认端口配置正确

### Redis 连接失败

1. **检查 Redis 服务**
   ```cmd
   redis-cli ping
   ```

2. **检查 Redis 配置**
   - 确认 Redis 服务已启动
   - 确认端口配置正确
   - 检查防火墙设置

### 前端启动失败

1. **检查 Node.js 版本**
   ```cmd
   node -v
   npm -v
   ```

2. **重新安装依赖**
   ```cmd
   rm -rf node_modules package-lock.json
   npm install
   ```

3. **检查端口占用**
   ```cmd
   netstat -ano | findstr :3000
   ```
